# Security and concerns

## Reporting a security problem

Please **don't open a public issue** for security problems. Report them privately on GitHub instead: open the repository's **Security** tab and choose **Report a vulnerability** ([direct link](https://github.com/deepak199922/talk-n-edit/security/advisories/new)). Include what you found, how to reproduce it, and which version you used (`node dist/index.js --check` shows it).

You'll get a reply as soon as possible, usually within a few days. Please give us reasonable time to fix the problem before you share details publicly.

Things that count as security problems include a way to make Talk-n-Edit read or write files outside the folders it's allowed to use, to run commands it shouldn't, or to send data off your computer.

Only the latest release is supported with fixes.

## Rights holders and other concerns

This repository contains only source code, documentation, open-licensed fonts, an MIT-licensed model and sound effects made by the project (see [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)). It does not contain or host third-party videos, music or other media.

If you believe anything in this repository infringes your rights, or you have another legal concern, please report it privately through the same **Report a vulnerability** form, or open an issue if it's fine for it to be public. Say what material it is, where it is in the repository, and why. Valid reports are acted on promptly, including removing material where appropriate. You can also use [GitHub's own process](https://docs.github.com/en/site-policy/content-removal-policies/dmca-takedown-policy).
